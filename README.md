# Office Placard — The Stapler

A make.fun bounty entry for **Office Artifacts: The One-Line Placard Contest**.

`main.ts` writes a single museum placard line (159 characters) to `/output/entry.txt`: a steel stapler, c. 1998, gift of the Accounts Department, recast as an ancient artifact that outlasted the company itself.

Run twice locally: byte-identical output.
